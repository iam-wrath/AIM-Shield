# Handoff for Christabel

Everything below is yours. The code works with the stand-ins I wrote; each item says where to put your version. Synthetic data only, never real personal data. Never commit `.env`.

## 0. Setup (10 min)
Follow the README "Setup" section. You need the Guard URL and your own team token in `.env` (shared by Kwaku, not in chat or git), plus an LLM key if you want live demos. Offline: the Attack Lab's **Replay recorded run** works with no keys.

Guard budget: 30 requests/minute, 1,000/day per team. We had used about 270 of the 1,000 by mid-day on 3 Oct (the real evaluation run is included). Check `GET /usage` before any big run, and use `--dry-run` first.

## 3. Attack library (yours)
- `attacks/starter.json` is generated by `attacks/make_starter.py` for the demo. Add **your own file** next to it (`attacks/christabel.json`, format `{"attacks":[{id, weakness, title, expected, turns:[...]}]}`): it appears in the Attack Lab dropdown automatically. Last turn of `turns` is the one judged. Pick `expected` as `allow`, `redact` or `block`.
- Aim for about 5 per weakness (W1, W2, W3, W5, W6) plus 10 harmless student-style questions, including harmless Twi/Pidgin.
