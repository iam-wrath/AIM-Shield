# Scam warnings (KwikPay support policy, synthetic)

A real network operator never asks for your MoMo PIN or one-time code by call, SMS or chat. If someone does, it is a scam.

Never approve a payment prompt you did not start, even if the caller says it is a refund or says the money was sent by mistake.

Never send money to a number to get your money back. Hang up and call the official short code yourself.
