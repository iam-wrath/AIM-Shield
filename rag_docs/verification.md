# Verifying your identity (KwikPay support policy, synthetic)

There are three levels. Level 0 is anonymous: we can answer general questions only. Level 1 is logged in: we can discuss your account. Level 2 is verified with a one-time code: we can start a reversal or a PIN reset.

The one-time code is six digits and is sent to your own registered number. Type it into the chat once. Staff will never ask you to read it out.

You can write to us in English, Twi or Pidgin.
