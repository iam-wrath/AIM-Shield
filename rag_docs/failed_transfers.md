# Failed transfers (KwikPay support policy, synthetic)

If a transfer fails but the money has left your wallet, KwikPay holds the amount safely and returns it automatically within 24 hours in most cases.

To check a failed transfer, quote the transaction ID, which starts with KP followed by eight digits. We only discuss a transaction with the customer who made it.

If the money has not returned after 24 hours, ask for a reversal. A reversal needs a verified customer: log in, then confirm the one-time code we send to your own registered number.
