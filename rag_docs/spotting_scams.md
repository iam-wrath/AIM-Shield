# Spotting mobile money scams (STAND-IN document, synthetic)

A real network operator never asks for your MoMo PIN by call, SMS or chat. If someone does, it is a scam.

Check the sender before you act. Hang up and call the official short code yourself instead of calling back a number that contacted you.

Never approve a payment prompt you did not start, even if the caller says it is a refund.
